# AVAIM0013 — Web Audio Player & Music Archive

Веб-аудиоплеер и архив треков для **AVAIM0013**.
Плеер автоматически сканирует папку `music/` репозитория GitHub ([VoidWolf13/AVAIM0013](https://github.com/VoidWolf13/AVAIM0013)) и воспроизводит треки в реальном времени с поддержкой эквалайзера, визуализаторов и фоновых звуковых ландшафтов.

---

## 📁 Структура папки для музыки

Чтобы треки появились в плеере:
1. Создайте папку `music/` в корне этого репозитория на GitHub.
2. Загрузите в неё аудиофайлы любого поддерживаемого формата (`.mp3`, `.flac`, `.wav`, `.ogg`, `.m4a`).
3. Плеер автоматически считает файлы, распознает названия, формат, битрейт и теги.

---

## 🚀 Как развернуть сайт на GitHub Pages

1. Скачайте архив `.zip` из Google AI Studio и распакуйте его.
2. Загрузите файлы в ваш репозиторий [https://github.com/VoidWolf13/AVAIM0013](https://github.com/VoidWolf13/AVAIM0013).
3. В настройках репозитория на GitHub:
   - Перейдите в **Settings** -> **Pages**.
   - В разделе **Build and deployment** выберите источник (Source) — **GitHub Actions** или **Deploy from a branch**.
   - Сайт будет доступен по адресу: `https://voidwolf13.github.io/AVAIM0013/`
