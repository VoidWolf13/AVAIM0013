# AVAIM0013 — Web Audio Player & Music Archive

Официальный веб-аудиоплеер и архив треков для **AVAIM0013**.
Плеер автоматически сканирует папку `music/` репозитория GitHub ([VoidWolf13/AVAIM0013](https://github.com/VoidWolf13/AVAIM0013)) и воспроизводит треки с поддержкой спектрограмм, эквалайзера, фоновых текстур и таймера сна.

## 🎵 Возможности

- **Динамическая синхронизация с GitHub** — сканирует папку `music/` репозитория и загружает аудиофайлы (.mp3, .flac, .wav, .ogg, .m4a, .aac) в реальном времени
- **4 визуализатора** — спектр, осциллограф, радиальный индикатор и космическая туманность (particles) на базе Web Audio API
- **3-полосный параметрический эквалайзер** — bass (180 Гц), mid (1.2 кГц), treble (6.5 кГц) с 6 пресетами
- **Таймер сна** — плавное затухание звука по истечении заданного времени
- **Полноэкранный Zen-режим** — Immersive визуализатор с автоскрытием интерфейса
- **Горячие клавиши** — полное управление с клавиатуры (Space, arrows, M/N/P/S/R/F/Esc)
- **Избранное** — сохранение любимых треков в localStorage
- **Поддержка очередей** — последовательное и случайное воспроизведение

Если при деплое возникает ошибка `Timeout reached, aborting!` или `Service Unavailable`:

## 📁 Структура папки с музыкой

1. Загружайте аудиофайлы (`.mp3`, `.flac`, `.wav`, `.ogg`, `.m4a`) в папку `music/` в корне репозитория.
2. Плеер мгновенно считает треки, определит форматы, битрейт и отобразит их в списке.
