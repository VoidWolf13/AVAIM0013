# AVAIM0013 — Web Audio Player & Music Archive

Официальный веб-аудиоплеер и архив треков для **AVAIM0013**.
Плеер автоматически сканирует папку `music/` репозитория GitHub ([VoidWolf13/AVAIM0013](https://github.com/VoidWolf13/AVAIM0013)) и воспроизводит треки с поддержкой спектрограмм, эквалайзера, фоновых текстур и таймера сна.

---

## ⚠️ Важная настройка для GitHub Pages (Устранение ошибки Timeout)

Если в GitHub Actions при деплое возникает ошибка `Timeout reached, aborting!`:
1. Перейдите в ваш репозиторий: **Settings** (Настройки репозитория).
2. В левом меню выберите пункт **Pages**.
3. В блоке **Build and deployment** найдите выпадающий список **Source**:
   - Переключите со стандартного *Deploy from a branch* на **`GitHub Actions`**.
4. После этого перейдите во вкладку **Actions** и запустите workflow заново (или сделайте новый `git push`).
5. Сайт автоматически развернется по адресу: [https://voidwolf13.github.io/AVAIM0013/](https://voidwolf13.github.io/AVAIM0013/)

---

## 📁 Структура папки с музыкой

1. Загружайте ваши аудиофайлы (`.mp3`, `.flac`, `.wav`, `.ogg`, `.m4a`) в папку `music/` в корне репозитория.
2. Плеер мгновенно считает треки, определит форматы, битрейт, теги и отобразит их в списке.

## 💻 Локальная разработка и сборка

```bash

npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта для публикации (генерирует папку dist/)
```
