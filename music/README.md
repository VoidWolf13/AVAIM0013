# Папка для аудиофайлов (music/)

Загружайте сюда ваши музыкальные треки (`.mp3`, `.flac`, `.wav`, `.ogg`, `.m4a`).

Плеер AVAIM0013 автоматически сканирует содержимое этой папки через GitHub API и формирует интерактивный список треков со спектрограммами, анализатором битрейта и поддержкой эквалайзера.
