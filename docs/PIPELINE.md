# Конвейер обработки треков — спецификация

**Статус:** решения приняты в обсуждении 2026-10-15, **не реализовано**.

## Папки (вне репозитория)

Корень: `/run/media/system/DATA/Github AVAIM0013/` (репозиторий — во вложенной `AVAIM0013/`).

| Папка | Назначение | В репозиторий |
|---|---|---|
| `Необработаные треки/` | инбокс: сюда кладутся сырые треки | нет |
| промежуточные (создать) | mastered WAV и рабочие файлы | нет |
| архив FLAC (создать) | flac-копии для архива | нет |
| `AVAIM0013/music/` | готовые mp3 | **да** |

Исходный файл после успешной обработки **удаляется** из инбокса.

## Порядок обработки (на каждый файл)

1. **Обрезка тишины в конце.** Неагрессивная: порог очень низкий (≈ −70…−80 dB), минимальная длительность 0.3–0.5 с. Затухание **сохраняется** — оно часто задумано. Короткий fade-out (20–50 мс) на срезе, чтобы не было щелчка. Тишину в начале **не трогаем**.
2. **Нормализация громкости.** EBU R128 через `ffmpeg loudnorm` (два прохода): интегральная громкость **−14 LUFS**, true peak **−1 dBTP**. Без «улучшайзинга» — только стандарт стриминга.
3. **Определение жанров.** Мультижанр (смесь допустима). ML-модель по аудио (Essentia/TensorFlow или CLAP) — выбор по результатам проверки запуском.
4. **Запись тегов** (см. ниже).
5. **Кодирование.** mp3 320 kbps → в `music/`; flac → в архив.
6. **Публикация.** `git add/commit/push` (пока **по подтверждению**; в будущем — сразу).

## Теги (принято)

| Поле | Значение |
|---|---|
| title | имя файла без расширения |
| artist / composer | `AVAIM0013` |
| genre | список жанров из анализа (`TCON` через `/`) |
| date / year | год |
| track | по порядку |

Под вопросом (см. ниже): `album`, `BPM` (`TBPM`), тональность (`TKEY`), настроение (`TXXX`).

## Имена файлов

Имя = название трека. Пробелы при необходимости заменяются на `_`.

## Объём обработки

Все файлы, лежащие в инбоксе на момент запуска (пачка).

## План инструментов

- `ffmpeg` — обрезка тишины, fade, loudnorm, кодирование;
- `pyloudnorm` — контрольный замер LUFS;
- Essentia/TensorFlow **или** CLAP — жанры (проверить установку на Fedora 44 / Python 3.14);
- `mutagen` — запись тегов;
- один CLI **`avaim`** + скилл **`track-pipeline`** (обёртка с правилами).

## Открытые вопросы

- Точные поля тегов: нужны ли BPM, тональность, настроение; значение `album`.
- Имена папок для промежуточных и архива FLAC.
- Поведение с уже отмастеренными треками (пропускать/помечать).
- Способ удаления исходника (корзина или безвозвратно).

## Контекст

Все текущие треки будут **перекачаны заново** и приведены к этому единому стандарту; ими заменят то, что лежит в проекте сейчас.
