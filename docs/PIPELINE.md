## Порядок обработки (на каждый файл)

1. **Обрезка тишины в конце.** Неагрессивная: порог очень низкий (≈ −70…−80 dB), минимальная длительность 0.3–0.5 с. Затухание **сохраняется**. Короткий fade-out (20–50 мс) на срезе. Тишину в начале **не трогаем**.
2. **Нормализация громкости.** EBU R128 через `ffmpeg loudnorm` (два прохода): **−14 LUFS**, true peak **−1 dBTP**. Без «улучшайзинга».
3. **Определение жанров.** Мультижанр. ML по аудио (Essentia/TF или CLAP) — выбор по проверке запуском.
4. **Запись тегов** (см. ниже).
5. **Кодирование.** mp3 320 kbps → в `music/`; flac → в `Дискография AVAIM0013/`.
6. **Публикация.** `git add/commit/push` (пока **по подтверждению**; в будущем — сразу).

## Теги

Базовый набор (обычные треки):

| Поле | ID3 | Значение |
|---|---|---|
| title | `TIT2` | имя файла без расширения |
| artist | `TPE1` | `AVAIM0013` |
| composer | `TCOM` | `AVAIM0013` |
| genre | `TCON` | список жанров из анализа (через `/`) |
| BPM | `TBPM` | Percival (справочник приоритетнее) |

Служебное поле:

| Поле | ID3 | Значение |
|---|---|---|
| processed | `TXXX:processed` | `1` — метка «обработан» |

Обложка **не пишется**.

### Исключение — опубликованные треки

Для треков, вошедших в официальные релизы под псевдонимами **`anton_void`** и **`AVAIM0013`**, дополнительно пишутся официальные **альбом** (`TALB`) и **год** (`TDRC`). Синглы отдельно не учитываются — их треки входят в альбомы (проверка — `docs/RELEASES.md`).

Оговорка: сайт AVAIM0013 теги **не читает** (`id3Parser.ts` — мёртвый код). Теги — для архива и сторонних плееров.

## Поведение с уже обработанными треками

Вариант **B (помечать)**. После обработки в тег пишется `TXXX:processed=1`. Если трек с этой меткой попадает в инбокс **повторно** — он **пропускается**: повторная нормализация неидемпотентна и портит звук.

### Дубли по имени

Если в инбокс попадает трек, чьё название уже есть в `music/` или `Дискография AVAIM0013/`, он **пропускается** как дубль — независимо от тега у исходника. Проверка по имени файла, до запуска конвейера. Пропущенный исходник **остаётся в инбоксе**.

## План инструментов

- `ffmpeg` — обрезка тишины, fade, loudnorm, кодирование;
- `pyloudnorm` — контрольный замер LUFS;
- Essentia/TensorFlow **или** CLAP — жанры (выбор по проверке запуском);
- `mutagen` — запись тегов (в т.ч. `TXXX:processed`);
- один CLI **`avaim`** + скилл **`track-pipeline`**.

## Результаты проверки запуском (2026-10-15)

Проверено на машине void (Fedora 44, Python 3.14 системный, GTX 1060):

- **ffmpeg 8.1.3** — все нужные фильтры на месте: `loudnorm`, `silencedetect`, `silenceremove`.
- **Essentia работает** — выбран **Essentia + TensorFlow** (самый точный из доступных вариантов). Установлен `essentia-tensorflow 2.1b6` в отдельный venv `~/.local/share/audio-venv` (**Python 3.12** — под 3.14 wheels нет).
- **Модели жанров** (лежат в `~/.local/share/essentia-models/`, ~20 МБ):
  - `discogs-effnet-bs64-1.pb` (18.3 МБ) — эмбеддинги, взят с GitHub `MTG/essentia-models`;
  - `genre_discogs400-discogs-effnet-1.pb` (2.06 МБ) — классификатор на 400 жанров, взят из `MeshDigital/ORBIT` (media.githubusercontent);
  - `genre_discogs400-discogs-effnet-1.json` — список классов, с HuggingFace (`Heyian/discogs-effnet-onnx`).
- **Грабли:** официальный сайт `essentia.upf.edu` **недоступен** — DNS `upf.edu` сломан (нет reachable authority), модели оттуда не скачать. Взяты с зеркал (GitHub / HF). Если понадобится перекачать — использовать эти источники, а не официальный.
- **Тест жанра** на треке `Space vacuum.mp3` прошёл: топ — `Electronic—Experimental` 10.5%, `Electronic—Ambient` 9.6%, `Rock—Experimental` 6.6%. То есть модель даёт **мультижанр с процентами** — берём несколько верхних.

### loudnorm — проверено

Двухпроходная нормализация на `Space vacuum.mp3`: вход **−8.33 LUFS** → выход **−14.1 LUFS**, true peak **−1.0 dBTP**. Контрольный замер `ebur128` подтвердил: `I = −14.1 LUFS`. **Работает, цель −14 LUFS достигается точно.**

### Обрезка тишины — наблюдение

Скан хвостов всех 110 текущих треков: **ни у одного хвост не тише −50 dB**. То есть в текущем архиве хвостовой тишины нет — но это уже отмастеренные треки. Свежие треки из генератора (с эхом) проверять отдельно — механизм готов, но пока не на чем испытать.
