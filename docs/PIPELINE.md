# Конвейер обработки треков — спецификация

**Статус:** решения приняты в обсуждении 2026-10-15, **не реализовано**.

## Папки (вне репозитория)

Корень: `/run/media/system/DATA/Github AVAIM0013/` (репозиторий — во вложенной `AVAIM0013/`).

| Папка | Назначение | В репозиторий |
|---|---|---|
| `Необработаные треки/` | инбокс: сюда кладутся сырые треки | нет |
| `Промежуточные/` | mastered WAV и рабочие файлы | нет |
| `Дискография AVAIM0013/` | архив FLAC | нет |
| `AVAIM0013/music/` | готовые mp3 | **да** |

Исходный файл после успешной обработки **удаляется** из инбокса.

## Порядок обработки (на каждый файл)

1. **Обрезка тишины в конце.** Неагрессивная: порог очень низкий (≈ −70…−80 dB), минимальная длительность 0.3–0.5 с. Затухание **сохраняется**. Короткий fade-out (20–50 мс) на срезе. Тишину в начале **не трогаем**.
2. **Нормализация громкости.** EBU R128 через `ffmpeg loudnorm` (два прохода): **−14 LUFS**, true peak **−1 dBTP**. Без «улучшайзинга».
3. **Определение жанров.** Мультижанр. ML по аудио (Essentia/TF или CLAP) — выбор по проверке запуском.
4. **Запись тегов** (см. ниже).
5. **Кодирование.** mp3 320 kbps → в `music/`; flac → в `Дискография AVAIM0013/`.
6. **Публикация.** `git add/commit/push` (пока **по подтверждению**; в будущем — сразу).

## Теги

Базовый набор (обычные треки):

| Поле | ID3 | Значение |
|---|---|---|
| title | `TIT2` | имя файла без расширения |
| artist | `TPE1` | `AVAIM0013` |
| composer | `TCOM` | `AVAIM0013` |
| genre | `TCON` | список жанров из анализа (через `/`) |
| BPM | `TBPM` | из анализа |

Служебное поле:

| Поле | ID3 | Значение |
|---|---|---|
| processed | `TXXX:processed` | `1` — метка «обработан» |

Обложка **не пишется**.

### Исключение — опубликованные треки

Для треков, вошедших в официальные релизы под псевдонимами **`anton_void`** и **`AVAIM0013`**, дополнительно пишутся официальные **альбом** (`TALB`) и **год** (`TDRC`). Синглы отдельно не учитываются — их треки входят в альбомы (проверка — `docs/RELEASES.md`).

Оговорка: сайт AVAIM0013 теги **не читает** (`id3Parser.ts` — мёртвый код). Теги — для архива и сторонних плееров.

## Поведение с уже обработанными треками

Вариант **B (помечать)**. После обработки в тег пишется `TXXX:processed=1`. Если трек с этой меткой попадает в инбокс **повторно** — он **пропускается**: повторная нормализация неидемпотентна и портит звук.

## Имена файлов

Имя = название трека. Пробелы при необходимости заменяются на `_`.

## Объём обработки

Все файлы, лежащие в инбоксе на момент запуска (пачка).

## Замена текущего архива

Всё, что лежит в репозитории сейчас, по мере обработки **заменяется** аналогами с новыми тегами.

## Удаление исходника

- **Сейчас (разработка/тестирование):** в корзину проекта `_Корзина-<дата>/`.
- **В будущем (боевой режим):** безвозвратно.

## План инструментов

- `ffmpeg` — обрезка тишины, fade, loudnorm, кодирование;
- `pyloudnorm` — контрольный замер LUFS;
- Essentia/TensorFlow **или** CLAP — жанры (выбор по проверке запуском);
- `mutagen` — запись тегов (в т.ч. `TXXX:processed`);
- один CLI **`avaim`** + скилл **`track-pipeline`**.

## Открытые вопросы
