## [1.2.0] — 2026-10-15

### Added
- `avaim`: пропуск дублей по имени — если трек с таким названием уже лежит в `music/` или `Дискография AVAIM0013/`, исходник из инбокса не обрабатывается повторно (повторная нормализация неидемпотентна и портит звук). Пропущенный исходник остаётся в инбоксе.

## [1.1.0] — 2026-10-15

### Added
- `avaim` — CLI конвейера обработки треков (вне репозитория, рядом с ним): обрезка хвостовой тишины, двухпроходный `loudnorm` (−14 LUFS / −1 dBTP), жанры Essentia+TF, BPM, кодирование mp3 320 + flac, запись тегов, корзина для исходников.
- `docs/RELEASES.md` — официальная дискография (anton_void, AVAIM0013) со списками треков; проверка, что синглы входят в альбомы.
- `docs/PIPELINE.md` — спецификация конвейера обработки треков (обновлена: статус «выполнено»).

### Changed
- `docs/PIPELINE.md`: финальный набор тегов (title, artist, composer, genre, BPM + служебная `TXXX:processed`); для опубликованных — исключение с официальными альбомом и годом; текущий архив заменяется по мере обработки.
- `docs/PIPELINE.md`: добавлены результаты проверки запуском — выбран Essentia+TensorFlow (venv на Python 3.12), модели жанров скачаны с зеркал (официальный `essentia.upf.edu` недоступен), двухпроходный `loudnorm` подтверждён (−14.1 LUFS, −1.0 dBTP).
- `music/`: весь архив пересобран — mp3 320 kbps с обновлёнными тегами.

### Fixed
- `avaim`: кодировщик переносил метаданные исходника (`TALB`, `TDRC`) в готовый файл — добавлен `-map_metadata -1`, теги пишутся с нуля.
- `avaim`: BPM определяется только методом Percival (Essentia) — по эталону «Известные темпы.txt» 6/10 точно и ни одной ошибки ×2 против 4/10 у кластерного голосования; теги BPM пересчитаны у 12 треков.

### Processed
- Инбокс обработан целиком: 114 треков, 0 ошибок. `music/` — 117 mp3, архив `Дискография AVAIM0013/` — 112 flac; все mp3 помечены `TXXX:processed=1`.
- Хвостовая тишина обрезана у 14 файлов; BPM из справочника «Известные темпы.txt» проставлен без расхождений (10/10).
- Убран дубль `Techno_v001.mp3` (кривое имя без тегов) — в `_Корзина-2026-10-15/`.
