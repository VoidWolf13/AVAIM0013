# Changelog

## [1.7.1] — 2026-10-15

### Removed
- `src/utils/id3Parser.ts` — мёртвый модуль (ни одного импорта; использовал `Buffer`, в браузере упал бы).
- `scripts/addTags.js`, `scripts/addTags.mjs` — скрипты тегирования через `node-id3`, не нужны (теги пишет конвейер `avaim`).
- Зависимости `node-id3`, `autoprefixer`, `esbuild`, `tsx` — не использовались в сборке и скриптах.
- Мёртвые экспорты: `inferMoodAndCategory` (githubScanner), `ARTIST_DESCRIPTION`, `GITHUB_REPO_URL`, `GITHUB_PAGES_URL` (data/tracks).

### Changed
- `PlayerControls`: убраны неиспользуемые импорты (`Radio`, `Activity`, `Disc3`), деструктуризация `setVisualizerMode`, локальная `audioUrl` и массив `visModes`; проп `onOpenZen` удалён из интерфейса.
- `AudioContext`: убран неиспользуемый импорт `DEFAULT_GITHUB_CONFIG`.
- `package.json`: `vite` больше не дублируется в `dependencies` и `devDependencies`; скрипт `clean` чистит только `dist` (упоминание несуществующего `server.js` убрано).
- Транзитивные уязвимости закрыты (`npm audit fix`): 2 high → 0.

## [1.7.0] — 2026-10-15

### Added
- Сайт: в списке жанров родительские жанры выделены полужирным — вычисляются как первый жанр в метаданных трека (конвейер всегда пишет родителя первым).

### Changed
- Сайт: список жанров заполняется сверху вниз по столбцам (CSS multi-column) вместо построчного порядка — алфавит читается по колонкам.
- Сайт: шрифт жанров увеличен до 13 px.
- Сайт: ряд сортировок и фильтров получил подложку (`rounded-xl bg-neutral-900/60 border`), как у кнопки «Показать/Скрыть список».

## [1.6.0] — 2026-10-15

### Changed
- Жанры: родитель — топ-1 по сумме; поджанры — глобальный топ-3 независимо от родителя, с абсолютным порогом 16 % (ниже — не пишется; ни один не прошёл — только родитель). Относительный порог убран. Было «родитель + 1..3 поджанра из родителя», стало компактнее: в среднем ~1.6 поджанра на трек.
- Пересчитаны жанры у 116 треков (`avaim genres`): изменено 71, уникальных жанров 52.

## [1.5.0] — 2026-10-15

### Changed
- Случайный режим переведён на «мешок» (shuffle-bag): список тасуется, треки играют по одному разу за круг — повторов нет, пока не проиграют все. Раньше каждый переход был независимым броском, отсюда частые повторы.

### Added
- История воспроизведения в случайном режиме: «назад» идёт по реально проигранным трекам, а не выбирает случайный заново.

## [1.4.1] — 2026-10-15

### Fixed
- Избранное привязано к имени файла вместо порядкового `id` — при добавлении треков список избранного больше не «переезжает» на чужие треки.
- Фон: `background-size: cover` вместо `100% auto` — фон выравнивается по высоте экрана, на вертикальных экранах края уходят за края по горизонтали (убран мобильный `150% auto`).

## [1.4.0] — 2026-10-15

### Added
- `avaim index` — сборка `music/index.json` из тегов готовых треков (жанры, BPM, альбом, год); вызывается автоматически в конце `process`. Сайт читает индекс одним запросом.
- Сайт: фильтр по жанрам — раскрывающаяся панель со списком жанров в 2–3 колонки, чекбоксы, мультивыбор (логика «ИЛИ»). Жанры берутся из метаданных конвейера.
- Сайт: режимы списка — сортировки «Новое» (дефолт) и «По имени», фильтры «Жанры» и «Избранное»; работают совместно.
- Сайт: под треком выводится список жанров (если есть в метаданных).

### Changed
- `index.html`: заголовок вкладки — `AVAIM0013` (было `AVAIM0013 — Audio Archive & Music Player`).

## [1.3.0] — 2026-10-15

### Added
- Автопубликация: `Обработать новые треки.sh` после успешной обработки сам коммитит и отправляет результат в GitHub (`avaim publish --push`). Отдельная команда осталась для ручного запуска.
- `avaim publish` стал идемпотентным: без изменений в индексе коммит не создаётся и команда не падает.

## [1.2.0] — 2026-10-15

### Added
- `avaim`: пропуск дублей по имени — если трек с таким названием уже лежит в `music/` или `Дискография AVAIM0013/`, исходник из инбокса не обрабатывается повторно (повторная нормализация неидемпотентна и портит звук). Пропущенный исходник остаётся в инбоксе.

## [1.1.0] — 2026-10-15

### Added
- `avaim` — CLI конвейера обработки треков (вне репозитория, рядом с ним): обрезка хвостовой тишины, двухпроходный `loudnorm` (−14 LUFS / −1 dBTP), жанры Essentia+TF, BPM, кодирование mp3 320 + flac, запись тегов, корзина для исходников.
- `docs/RELEASES.md` — официальная дискография (anton_void, AVAIM0013) со списками треков; проверка, что синглы входят в альбомы.
- `docs/PIPELINE.md` — спецификация конвейера обработки треков (обновлена: статус «выполнено»).

### Changed
- `docs/PIPELINE.md`: финальный набор тегов (title, artist, composer, genre, BPM + служебная `TXXX:processed`); для опубликованных — исключение с официальными альбомом и годом; текущий архив заменяется по мере обработки.
- `docs/PIPELINE.md`: добавлены результаты проверки запуском — выбран Essentia+TensorFlow (venv на Python 3.12), модели жанров скачаны с зеркал (официальный `essentia.upf.edu` недоступен), двухпроходный `loudnorm` подтверждён (−14.1 LUFS, −1.0 dBTP).
- `music/`: весь архив пересобран — mp3 320 kbps с обновлёнными тегами.

### Fixed
- `avaim`: кодировщик переносил метаданные исходника (`TALB`, `TDRC`) в готовый файл — добавлен `-map_metadata -1`, теги пишутся с нуля.
- `avaim`: BPM определяется только методом Percival (Essentia) — по эталону «Известные темпы.txt» 6/10 точно и ни одной ошибки ×2 против 4/10 у кластерного голосования; теги BPM пересчитаны у 12 треков.

### Processed
- Инбокс обработан целиком: 114 треков, 0 ошибок. `music/` — 117 mp3, архив `Дискография AVAIM0013/` — 112 flac; все mp3 помечены `TXXX:processed=1`.
- Хвостовая тишина обрезана у 14 файлов; BPM из справочника «Известные темпы.txt» проставлен без расхождений (10/10).
- Убран дубль `Techno_v001.mp3` (кривое имя без тегов) — в `_Корзина-2026-10-15/`.

### Added (планируется)
- Чтение реальных ID3-тегов (`src/utils/id3Parser.ts` написан, но не подключён).
- Сохранение пользовательских метаданных треков (`saveCustomTrackMetadata` не вызывается).
- Теги релизов.

### Changed (планируется)
- Задействовать или удалить мёртвый код (`id3Parser`, `inferMoodAndCategory`).
- Устойчивость к лимиту GitHub API.
